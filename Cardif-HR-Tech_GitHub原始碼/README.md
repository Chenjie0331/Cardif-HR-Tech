# Cardif-HR Tech

2026 法國巴黎人壽校園黑客松的 HR 招募與任用互動原型。本儲存庫為網站第 37 版的原始碼快照。

首頁位於儲存庫根目錄的 **index.html**。使用 HTML、CSS、JavaScript 與本機附帶的 GSAP，不需要建置步驟。

## 功能

- 履歷閱讀、重點整理、人才標籤與原文定位。
- 職缺與資格查核、職缺共用權重及全體應徵者初步比較。
- 面試問題編輯、訪談紀錄、人工評估、文件預覽與匯出。
- 應徵者模擬填寫入口。
- 保留四種身分定義，目前只開放 HR 登入。

## 開啟方式

以瀏覽器開啟根目錄的 index.html，或將儲存庫根目錄交給靜態網站服務。首次開啟先顯示首頁，HR 工作區可使用登入頁提供的展示帳號。

既有展示站：[Cardif-HR Tech](https://cardif-hr-workspace.a0963515.chatgpt.site/)。本次上傳原始碼沒有啟用 GitHub Pages。

安裝 Node.js 後執行 npm test。本專案的測試不需要安裝額外 npm 套件。

## 展示範圍

使用虛構人選、模擬資料及規則流程，目前未串接 AI 模型或企業正式系統。示範初評可以由 HR 修改，參考分數不是錄用機率。

帳號、筆記、履歷投遞及面試紀錄保存在使用者自己的瀏覽器，不會隨原始碼上傳 GitHub，也不會跨裝置同步。登入機制僅供原型展示，請勿放入真實個資或重用正式密碼。

後續規劃包含 AI 資訊抽取、追問建議與訪談摘要，以及各部門、主管與員工對應的帳號、權限及多人協作。
